# 에셋 폴더 안내

이 폴더에 게임 리소스를 추가하세요.

## 필요한 파일

### 캐릭터 이미지 (characters/)
- aa/normal.png, aa/happy.png, aa/sad.png, aa/angry.png
- bb/normal.png, bb/happy.png, bb/sad.png, bb/angry.png
- 권장 크기: 1000x2000px (세로로 긴 형태)
- 투명 배경 PNG 권장

### 배경 이미지 (backgrounds/)
- classroom.jpg (교실)
- school_yard.jpg (학교 운동장)
- 권장 크기: 1920x1080px

### 컷신 이미지 (cutscenes/)
- ending_a.jpg
- ending_b.jpg
- 권장 크기: 1920x1080px

### 음악 파일 (music/)
- title.mp3 (타이틀 BGM)
- daily.mp3 (일상 BGM)
- ending.mp3 (엔딩 BGM)
- MP3 또는 OGG 형식

### 아이콘 (icon/)
- save.svg, load.svg, exit.svg
- talk.svg, place.svg, story.svg
- enter.svg, delete.svg, x.svg
- musicon.svg, musicoff.svg
- SVG 형식 권장 (24x24px)

## 임시 파일 사용

테스트용으로 다음 사이트에서 무료 이미지를 사용할 수 있습니다:

- **배경**: https://unsplash.com (무료 이미지)
- **캐릭터**: https://www.pixiv.net (일러스트, 라이선스 확인 필요)
- **음악**: https://freesound.org (무료 음향)
- **아이콘**: https://heroicons.com (무료 SVG 아이콘)

## 저작권 주의

상업적 사용 시 반드시 라이선스를 확인하세요.
